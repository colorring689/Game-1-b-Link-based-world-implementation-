# Echo tower

This is a simple link-based story game made for a class assignment.

## About the Game

You play as someone who wakes up after a boat crash near an abandoned research station. The only way to escape is to explore the area, restore power, and reach the lighthouse to send a signal.

Along the way, you can discover what happened in the station through different locations and a radio system.

## Features

- Link-based world with multiple locations
- Fuse puzzle to restore power
- Radio system with different signals
- Basic inventory system

## How to Play

Run the project using a local server and open `index.html`.
